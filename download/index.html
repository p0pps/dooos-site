Dooos

Mac download

Dooos for Mac 0.1.0 (2) requires macOS 14 or later.

Download Dooos for Mac

Install

  1. Download and open the ZIP.
  2. Move DooosMac.app to the Applications folder.
  3. Open DooosMac.app.
  4. Make sure the Mac is signed into iCloud with an Apple Account that has accepted an invitation to the Dooos household.

Verification

The app is Developer ID-signed and notarized by Apple.

SHA-256: 26f45e4bbcc93727c2f7910190ac376b93ce9347af314157004cb8b510536df2

Updates

This first version uses manual updates. Download a newer ZIP and replace the app in Applications. Automatic updates may be added later.

Before using real data

Verify household syncing between the owner, other iPhone participants, and this Mac. Cloud sync is not a backup; export a JSON backup before destructive changes.
