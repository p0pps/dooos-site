Dooos

Mac download

Dooos for Mac 0.1.0 (58) requires macOS 14 or later.

Download Dooos for Mac

Install

  1. Download and open the ZIP.
  2. Move Dooos.app to the Applications folder.
  3. Open Dooos.app.
  4. Make sure the Mac is signed into iCloud with an Apple Account that has accepted an invitation to the Dooos household.

Verification

The app is Developer ID-signed and notarized by Apple.

SHA-256: 87847aed774c8eca4170dd958bf427eb0312af39a4afb4562ae93d21f80d2c0b

Updates

If you have Build 6, download Build 58 and replace the app in Applications once. Build 9 and later can use Dooos → Check for Updates, and the app checks automatically.

If you are updating from Build 5 or earlier, quit the old DooosMac.app, install and open Dooos.app, confirm your household appears, and then remove DooosMac.app.

Before using real data

Verify household syncing between the owner, other iPhone participants, and this Mac. Cloud sync is not a backup; export a JSON backup before destructive changes.
